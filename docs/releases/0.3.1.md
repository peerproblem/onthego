# ONTHEGO 0.3.1

This patch protects files that leave the handoff policy and makes native session import recoverable after workspace delivery.

## Upgrade both devices

Install `@jbaehova/onthego@0.3.1` on both devices before the next peer handoff. New packages use snapshot schema 3 with signed `retained_paths` and `payload_sizes`. This version reads schema 2 and 3. Older receivers reject schema 3 packages. Peer negotiation now requires `snapshot-v3` and `session-scope`.

Project policy and handoff receipts stay on schema 2. Recovery state is stored separately. Receipts written with `--no-sessions` contain the new optional `selection.none` field and cannot be read after downgrading to 0.3.0.

## Rotate previously transferred credentials

If you handed off untracked credential files such as `.npmrc` with ONTHEGO 0.3.0 or earlier, rotate the corresponding tokens. Their plaintext bytes may remain in both devices' `.git/objects`, referenced by earlier WIP commits. Garbage collection does not remove objects still referenced by that history. This release does not rewrite or delete existing Git history.

New handoffs exclude these credential candidates automatically. An explicit `--include-secret` transfers permitted files as encrypted supplemental data outside Git objects. Files that were already managed remain on the receiver when policy stops sending them, with a warning. Actual source deletions still propagate.

## Changes

- Refuse case and Unicode normalization collisions before changing workspace files. Replace individual files and symlinks atomically.
- Authenticate the manifest before writing payloads. Check signed payload names and exact sizes. Highly compressible valid packages now round-trip.
- Reject invalid agents and unknown schema 2 policy keys before session selection.
- Retry failed session imports with the same package or `onthego sessions recover`. Preserve workspace edits made after delivery, retain every pending import across consecutive failures, and report pending recovery in status and JSON.
- Pin pending export commits until acknowledgment or expiry so Git GC cannot break offline return handoffs. Pruning uses the workspace lock. Backup listing and undo work without a valid policy file.
- Add `--no-sessions` and `--session-conflict`. Keep `--sessions` as a deprecated alias. Validate dry-run options consistently and report omitted local checks.
- Fail explicitly requested missing session IDs. Report malformed sessions and adapter failures without blocking healthy adapters. Import only touches agent homes actually present in the package.
- Cancel stalled peer stdin reads promptly, limit their size, restore default behavior for a second interrupt, and forward npm launcher signals without leaving a native child behind.
- Escape terminal control characters in text output. Distinguish internal failures (`E_INTERNAL`, exit 1) and cancellation (`E_CANCELED`, exit 130) from input errors.
- Update compression and cryptography dependencies, build releases with Go 1.27.2, pin workflow actions and run scheduled vulnerability checks.

See the README for commands and the complete public error-to-exit-status table.
