# ONTHEGO 0.4.0

This release is about getting set up and moving between devices with less thinking. The handoff engine, file formats, and wire protocol are unchanged from 0.3.1, so 0.4.0 and 0.3.1 devices can hand off to each other.

## One command to move

`onthego sync <device>` compares this workspace with the device's copy and pushes or pulls in the safe direction. It pulls back work you handed off, pushes new local work, does nothing when both sides match, and stops with clear options when both sides changed. `--dry-run` shows the decision.

## Easier setup

- `onthego device add <name> --install` detects the device's OS and CPU and copies the matching onthego binary to `~/.local/bin` over SSH. The npm package already contains every platform, so servers need neither Node.js nor internet access. `onthego device install <name>` upgrades a paired device to your version.
- `onthego tailscale` checks Tailscale, lists tailnet devices with their online state, and explains what each device still needs. `onthego device add <name> --tailscale [user@]<device>` pairs by tailnet name. See the new [Tailscale guide](https://github.com/peerproblem/onthego/blob/main/docs/tailscale.md).
- `install.sh` installs the release binary with checksum verification on machines without Node.js:
  `curl -fsSL https://raw.githubusercontent.com/peerproblem/onthego/main/install.sh | sh`
- SSH failures now explain the fix: missing keys, unknown or changed host keys, refused connections, unreachable or unresolved hosts, and a missing onthego on the device. They use the documented exit status 4 instead of 1. On an interactive terminal, `device add` offers to confirm an unknown host key.
- `onthego device path <name> [path]` shows or sets where the current project lives on a device, and `device list` shows it. `remote set` still works with a deprecation warning.
- Shell completion with device names: `onthego completion bash|zsh|fish`.

## Quieter, clearer output

- Agent disclaimers appear once, only when sessions actually travel. Workspace-only handoffs no longer print them.
- Secret candidates are reported once, with the exact `--include-secret` command.
- The `cd` hint appears only when the workspace landed somewhere else, and the session counts only when sessions were involved.
- `status` suggests the next command when the work is on another device. `doctor` reports SSH, Tailscale, and the device's onthego version.
- `--help` groups commands into everyday, setup, and recovery, and `init` prints the next steps.

## Removed

- The undocumented `pass` alias for `push`.
- Internal planning files and the duplicate example policy from the repository.

## Upgrading

`npm update -g @jbaehova/onthego`, then `onthego device install <name>` for each SSH device. No migration is needed.
