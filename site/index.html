Works with the machines you have.

If one can ssh into the other, you're set.

Same Wi‑Fi

ssh-copy-id me@laptop.local
onthego device add laptop \
  --host me@laptop.local --install
onthego sync laptop

Anywhere, with Tailscale

onthego tailscale
onthego device add laptop \
  --tailscale me@laptop --install
onthego sync laptop

Your VPS

onthego device add vps \
  --host me@vps.example.com --install
onthego sync vps

No Node.js? Use curl.

curl -fsSL https://raw.githubusercontent.com/\
peerproblem/onthego/main/install.sh | sh

Tech Specs

Platforms

macOS and Linux, arm64 and amd64

Install

npm install -g @jbaehova/onthego
or the curl installer, or build from source

Needs

Git and OpenSSH on each machine

Connection

Your own SSH. Tailscale optional.

Encryption

age for the receiving device, Ed25519 signatures, pinned device keys

Agents

Codex CLI and Claude Code

Copied

Staged, unstaged, and untracked work, missing Git history, recent agent sessions

Not copied

.env and other credential files, node_modules, caches, Git config, agent logins

Conflicts

Never merged. sync stops and a Git backup keeps the replaced side.

Price

Free. MIT license. No account, no server.
