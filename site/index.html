The one command

It figures out which way.

You never choose push or pull. sync checks what changed on each side since the last handoff, and only moves work away from the side that stayed put. Changed on both? It stops and asks. Nothing gets merged behind your back.

Setup

Any machine you can ssh into.

Run commands from whichever side can reach the other. Your laptop can push to a VPS and pull it back, and the VPS never needs to find your laptop.

1

Same Wi-Fi

Flip on Remote Login (macOS) or sshd (Linux), copy your key once, pair.

ssh-copy-id me@laptop.local
onthego device add laptop \
  --host me@laptop.local --install
onthego sync laptop
2

Anywhere, via Tailscale

Pair by device name. onthego tailscale lists your tailnet and what is missing.

onthego tailscale
onthego device add laptop \
  --tailscale me@laptop --install
onthego sync laptop
3

Your VPS

No Node.js needed up there. --install ships the right binary; device install upgrades it.

onthego device add vps \
  --host me@vps.example.com --install
onthego sync vps   # send it up
onthego sync vps   # bring it back
curl -fsSL https://raw.githubusercontent.com/peerproblem/onthego/main/install.sh | sh

FAQ

Okay, but…

Is it a sync daemon that runs all the time?

Nope. You run it when you switch machines, so it's always obvious which device has the work. Nothing watches your files in the background.

Do I need an account, a server, or an API key?

No, no, and no. Your devices talk directly over the SSH you already use. No relay, no cloud copy, no AI. It just moves your files.

What if I edited on both machines?

sync stops and tells you your options. Whatever gets replaced is saved as a Git backup first, and onthego undo brings it right back.

Will my .env and tokens leak over?

Not unless you ask. Credential files are spotted and left behind. If you really want one over there, --include-secret sends it encrypted, never inside Git objects.

Which agents and platforms?

Codex CLI and Claude Code, on macOS and Linux (arm64 and amd64). Sessions resume by ID with each agent's own resume command; you sign in to the agent on each device.
