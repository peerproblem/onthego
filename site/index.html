Set up in a minute.

Same Wi‑Fi

ssh-copy-id me@laptop.local
onthego device add laptop \
  --host me@laptop.local --install
onthego sync laptop

Anywhere, with Tailscale

onthego tailscale
onthego device add laptop \
  --tailscale me@laptop --install
onthego sync laptop

Your VPS

onthego device add vps \
  --host me@vps.example.com --install
onthego sync vps   # up
onthego sync vps   # and back
